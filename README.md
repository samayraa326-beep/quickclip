# QuickClip

Instant video-editor marketplace MVP.

## Product
Customer requests an edit, gets a transparent estimate, and is matched with an available editor. Editors can manage availability and accept jobs.

## MVP scope
- Customer request flow
- Editor availability
- Instant matching
- Pricing estimate
- Job status
- Portfolio/editor profiles
- Reviews

## Next
Connect this frontend to Supabase for auth, jobs, storage, realtime status, and payments.
